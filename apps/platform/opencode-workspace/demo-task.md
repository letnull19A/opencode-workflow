# Демо-задача для opencode-chain

Платформа получает карточку «починить ночной деплой», агент должен:

1. Прочитать этот файл и суммировать задачу одним абзацем.
2. Составить короткий план из 3 шагов по этому резюме.

Контекст: ночной деплой падает на шаге миграций, потому что job `migrate`
стартует раньше, чем поднимается база. Откат — вручную через `rollback.sh`.
Требование: деплой должен либо проходить целиком, либо не трогать прод.
