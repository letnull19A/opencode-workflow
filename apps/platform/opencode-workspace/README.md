# opencode-workspace — песочница локального opencode-сервера (демо)

Рабочая директория pm2-app `opencode` (`scripts/opencode-server/server.sh`):
агентные сессии демо (например `opencode-chain`) работают здесь, а не в корне
репозитория — чтобы не засорять его.

Директория осознанно НЕ в `.gitignore`/`.dockerignore`: это часть проекта
(демо-фикстуры едут в образ вместе с кодом).

- `demo-task.md` — фикстура для демо-цепочки create → summarize → plan.
- Промпты демо — только чтение/текст, без записи файлов.
